Trong môn Kỹ năng Nghề nghiệp (SS004), việc chuẩn bị một Portfolio chỉn chu là bước đệm quan trọng để ứng tuyển vị trí Thực tập sinh hoặc Lập trình viên. Nhóm 9h53 thực hiện dự án này nhằm tạo ra một ví dụ minh họa trực quan về Personal Website chuẩn chỉnh.


Trang web này tập trung chứng minh tính hiệu quả của việc tự code & deploy một website cá nhân thực tế lên môi trường Internet, giúp nhà tuyển dụng đánh giá cao tư duy làm sản phẩm của bạn.

Tổng quan 5 Style Portfolio

Các phong cách thể hiện Portfolio phổ biến dành cho dân IT

Style 1

PDF Standard Canvas

Dạng hồ sơ tài liệu truyền thống. Nhẹ nhàng, dễ in ấn và thích hợp đính kèm qua Email.

Style 2 (Trang này)

Personal Website (Deploy)

Website cá nhân tùy biến giao diện, sử dụng hiệu ứng tương tác mượt mà và deploy công khai.

Style 3

Interactive / Game-like

Dạng trải nghiệm tương tác hoặc game 2D giúp người xem vừa khám phá vừa tương tác.

Style 4

GitHub README Profile

Gọn gàng ngay trên GitHub Profile, phù hợp cho Backend Devs tập trung thể hiện Code.

Style 5

Minimalist Tech Blog

Kết hợp chia sẻ bài viết kỹ thuật & hồ sơ năng lực cá nhân một cách tối giản.
