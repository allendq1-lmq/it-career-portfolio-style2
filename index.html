Môn học Kỹ năng Nghề nghiệp (SS004) yêu cầu sinh viên sẵn sàng cho thị trường lao động. Nhóm 9h53 thực hiện đề tài phân tích và xây dựng mẫu 5 phong cách Portfolio phổ biến nhất hiện nay.


Trang web bạn đang xem chính là ví dụ minh họa trực tiếp cho Style 2: Personal Website (Deploy thật) — minh chứng cho tư duy lập trình và khả năng hoàn thiện sản phẩm thực tế.

Phân tích 5 Style Portfolio

Tổng hợp từ số liệu Báo cáo Thị trường Tuyển dụng ITviec

Style 1

GitHub-as-portfolio

README profile + pinned repos + lịch sử commit làm bằng chứng trực tiếp. Phù hợp nhất cho Back-end/Full-stack/Data — đúng nhóm mà báo cáo ITviec ghi nhận nhu cầu tuyển cao nhất (Back-end 54,2%, Full-stack 45,8%, tr.24).

Nhược điểm: không có ngữ cảnh, nhà tuyển dụng phải tự suy ra vấn đề bạn giải quyết.

Style 2 (Trang hiện tại)

Personal website (deploy thật)

Trang web tự làm bằng chính stack đang học (React/Next.js…), có demo project chạy được, link GitHub, CV. Đây là style "nặng ký" nhất vì vừa chứng minh kỹ năng lập trình vừa là sản phẩm portfolio. Hợp với Front-end/Full-stack.

Style 3

Notion-based portfolio

Dùng Notion làm trang case-study: mỗi dự án viết bối cảnh — vai trò — quyết định — kết quả. Không cần biết deploy web, dựng nhanh, sửa dễ. Rất phù hợp sinh viên năm 3 chưa vững kỹ thuật web nhưng cần trình bày project môn học/đồ án. Đây cũng là hình thức khớp với điểm mình từng nói: portfolio thời AI cần thể hiện quá trình ra quyết định, không chỉ code.

Style 4

LinkedIn profile là portfolio chính

Ở Việt Nam, nhiều sinh viên/fresher dùng LinkedIn thay vì trang riêng — đỡ chi phí, tận dụng sẵn mạng lưới. Báo cáo ITviec cho thấy LinkedIn là kênh tìm việc/freelance đứng thứ 3 (31,8% với freelance, tr.67), thấp hơn hẳn "bạn bè/người quen" (63,6%) — phản ánh đúng thực trạng tuyển dụng VN vẫn dựa nhiều vào quan hệ hơn là portfolio công khai.

Style 5

PDF/case-study portfolio (dạng doc gửi kèm CV)

File PDF trình bày 2-3 dự án tiêu biểu, kèm hình ảnh, số liệu kết quả. Không cần hạ tầng kỹ thuật, dễ gửi qua email tuyển dụng — hợp với Tester/QA-QC, Business Analyst hoặc Data Analyst, nơi "sản phẩm" là report/test case chứ không phải code chạy được.

"Talent without working hard is nothing. Tương tự trong lập trình, kỹ năng tốt mà không biết cách trình bày trong Portfolio thì nhà tuyển dụng cũng không thể biết bạn giỏi ra sao!"
- Tinh thần CR7 & Đồ án SS004
